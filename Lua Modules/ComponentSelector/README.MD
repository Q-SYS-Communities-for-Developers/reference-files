# This module helps in selecting components

# GetComponentType() takes in a string for the requested component type and returns a list of all the matching components in the design that have script access enabled.

# SetComponent() takes in a control and returns either a valid component or nil.

#### Please Note that SetComponent() requires a combobox control and not a string. This is so the module can change the color/string of the combobox as part of the error checking process.
